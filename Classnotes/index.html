Class Notes

Five modules of worked Unity examples, each with notes, a playable WebGL build and the full Unity project. Start with the Unity help page, then work through the modules in order.

Start with Module 1 → Unity help GitHub repository ↗

Getting started

⬇ Install Unity 6000.3.11f1 The version every example uses, plus the modules to install.
⚠ Don't upgrade mid-class Once Unity is installed and working, stay on that version.
? Problems Q&A WebGL build errors, missing IntelliSense, missing UI options.
